# Frick

Frick is a prototype drop-in data framework: one versioned schema, compact binary frames, a local replicated client runtime, a SQLite-backed sync server, and demo clients.

## What is in this MVP

- `packages/protocol`: schema manifest types, field-id object packing, and MessagePack frame encoding.
- `packages/core`: UI-agnostic client runtime with query subscriptions, mutation sending, delta application, and sync status.
- `packages/react`: `FrickProvider`, `useQuery`, `useMutation`, and `useSyncStatus`.
- `apps/server`: Node server using `node:sqlite`, WebSocket sync at `/_frick/sync`, and REST reads for native demos.
- `apps/web`: Vite React demo consuming live server data.
- `apps/ios`: real SwiftUI iOS app project generated by XcodeGen.
- `apps/android`: real Android Compose app project.
- `Tiltfile`: local runtime dashboard for server and web resources.

## Local ports

- Server: `http://127.0.0.1:4099`
- Web: `http://127.0.0.1:5173`
- Sync WebSocket: `ws://127.0.0.1:4099/_frick/sync`

## Commands

```bash
pnpm install
pnpm test
pnpm typecheck
pnpm run server
pnpm run web
pnpm tilt
```

Native demos:

```bash
pnpm ios:generate
pnpm ios:build
pnpm android:build
pnpm android:install
```

The iOS simulator reads `http://127.0.0.1:4099`. The Android emulator reads `http://10.0.2.2:4099`.
