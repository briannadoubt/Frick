# Superpowers plans

These are implementation plans written using the [Superpowers skill
collection](https://github.com/obra/superpowers) plan format, which the
maintainers use to drive subagent-led implementation runs. Each plan is
a single Markdown file with a "REQUIRED SUB-SKILL" header, task
checkboxes, and per-task step lists — readable as a normal design doc
even if you don't use Superpowers.

These plans capture *how* a slice was shipped (file lists, test names,
acceptance criteria) rather than *what* the framework exposes. For
public-facing framework documentation, start with [`docs/onboarding.md`](../onboarding.md);
for architectural decisions and slice motivations, see
[`internal/specs/`](../../internal/) and [`internal/plans/`](../../internal/).

The contents are present-tense as of authoring and will read as
out-of-date once the slice ships. The code, public docs, and
[`CHANGELOG.md`](../../CHANGELOG.md) are authoritative for current
behavior.
