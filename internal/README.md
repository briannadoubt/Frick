# Internal planning docs

These are the design specs and delivery plans the maintainers wrote while building Frick. They are kept in the repo for traceability — every shipped slice should be reachable from the spec and plan that motivated it — but they are **not** part of the public documentation set.

Public docs live under [`docs/`](../docs/). If you're reading this from a published package or a fresh clone and trying to learn the framework, start with [`docs/onboarding.md`](../docs/onboarding.md).

The contents are written in the present tense relative to the moment they were authored, so they will read as out-of-date once shipped. Don't rely on them for current-state truth; the code and the public docs are authoritative.
